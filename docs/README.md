# docs 目录地图

本页只提供文档导航，链接均相对于本目录。

| 文件 / 目录 | 用途 |
| --- | --- |
| [adr/](adr/) | 记录重要技术决策、取舍及其依据。 |
| [figures/](figures/) | 保存设计图的 Mermaid 图源及参考图。 |
| [learning/](learning/) | 记录分节学习过程、实际验证、疑问与 AI 使用情况。 |
| [modules/](modules/) | 按模块说明职责、调用链、异常边界和验证方式。 |
| [evidence/](evidence/) | 保存本地检查、CI 与验收结果的可核对证据。 |
| [loadtest/](loadtest/) | 归档压测方案与结果。 |
| [revisions/](revisions/) | 保存设计修订的变更说明与历史记录。 |
| [interview-qa.md](interview-qa.md) | 整理模块设计取舍、瓶颈与面试复盘问答。 |
| [ai-workflow.md](ai-workflow.md) | 记录本项目已确认的协作约定。 |
| [development-workflow.md](development-workflow.md) | 提供项目准备方案，说明开发过程与方法。 |
| [project-design.md](project-design.md) | 持续维护项目设计，作为项目范围与设计的唯一依据。 |

三者分工：project-design.md 是持续维护的主本；development-workflow.md 是准备方案（过程与方法）；ai-workflow.md 是协作约定。
